## ⚡ Featured Project — StuntLytics

> **A child-growth analytics and decision-support workspace that combines regional monitoring, geospatial risk intelligence, machine learning screening, evidence exploration, and AI-assisted insights in one system.**

[![Repository](https://img.shields.io/badge/View-Repository-181717?style=for-the-badge&logo=github)](https://github.com/zaenalSamsul/StuntLytics-Productiion)
![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Next.js](https://img.shields.io/badge/Next.js-000000?style=for-the-badge&logo=nextdotjs&logoColor=white)
![FastAPI](https://img.shields.io/badge/FastAPI-009688?style=for-the-badge&logo=fastapi&logoColor=white)
![Elasticsearch](https://img.shields.io/badge/Elasticsearch-005571?style=for-the-badge&logo=elasticsearch&logoColor=white)
![Docker](https://img.shields.io/badge/Docker-2496ED?style=for-the-badge&logo=docker&logoColor=white)

| | |
|---|---|
| **Purpose** | Decision support for monitoring child-growth and stunting-risk signals across regions |
| **Core Features** | Executive dashboard, regional risk map, data explorer, correlation & trend analysis, family screening, health insights, audit trail |
| **Architecture** | **Next.js workspace → FastAPI Evidence API → Elasticsearch**, with local ML screening and optional Gemini-powered narrative insights |
| **AI / Data** | scikit-learn screening pipeline, aggregated evidence generation, analytics engine, optional Gemini integration |
| **Infrastructure** | Elasticsearch, Kibana, Redis, Docker Compose, automated data ingestion and testing |

**Why I highlight it:** StuntLytics represents the kind of work I enjoy most — combining **data engineering, machine learning, backend systems, analytics, UI, and GenAI** into one cohesive application.
